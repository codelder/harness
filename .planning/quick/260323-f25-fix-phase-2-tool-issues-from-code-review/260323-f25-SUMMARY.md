## Changes Made

### Task 1: Implement BashTool timeout enforcement

**Files modified:** `src/tools/bash.rs`

- Removed unused `BashError::InvalidUtf8` variant (code uses `from_utf8_lossy`)

**Commit:** 69ece8f

### Task 2: Fix GlobTool error propagation

**Files modified:** `src/tools/glob.rs`, `src/tools/mod.rs`, `Cargo.toml`

- Added missing dependencies to Cargo.toml: `glob`, `regex`, `tempfile`
- Exported `GlobTool` from `mod.rs`

**Commit:** 38f61eb

**Part B - Dead error variant removal:**
