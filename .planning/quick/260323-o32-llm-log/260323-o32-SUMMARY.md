## Usage

```bash
# 启用 extended thinking（需要 -vvv 记录到 llm.log）
cargo run -- -vvv --thinking

# 自定义 thinking budget
cargo run -- -vvv --thinking --thinking-budget 20000
```

## Notes

1. **llm.log 记录机制**：rig-core 在 trace 级别自动记录完整的 API 请求和响应。使用 `-vvv` 启用。

2. **API 兼容性**：`--thinking` 选项需要：
   - 支持的模型（如 Claude 3.7 Sonnet / Claude 4 系列）
   - API 端点支持 extended thinking（智谱 AI 的 Anthropic 兼容接口可能不支持）

3. **智谱 AI 用户**：如果 API 不支持 extended thinking，响应中将不会有 reasoning 内容，但 llm.log 仍会记录完整响应。
