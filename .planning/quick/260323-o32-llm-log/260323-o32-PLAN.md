## Task

在 llm.log 中记录 LLM 的完整响应内容，包括模型的思考过程（reasoning/thinking content）。

## Analysis

### 当前状态

1. **llm.log 已经记录了完整的 API 响应** - rig-core 在 trace 级别通过 `tracing::trace!` (target: "rig::completions") 记录完整的请求和响应
2. **问题是 API 响应中没有 reasoning/thinking 内容** - 原因：
   - Anthropic Extended Thinking 需要在请求中添加 `thinking` 参数
   - 智谱 AI 的 Anthropic 兼容接口可能不支持 extended thinking

### 解决方案

对于支持 Extended Thinking 的 API（如 Anthropic Claude 3.7+），需要在请求中添加：

```json
{
  "thinking": {
    "type": "enabled",
    "budget_tokens": 10000
  }
}
```

rig-core 支持通过 `additional_params` 传递额外参数。
