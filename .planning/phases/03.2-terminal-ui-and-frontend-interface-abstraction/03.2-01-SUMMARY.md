- Used a named `SESSION_START_TURN_ID` constant instead of repeating a magic `0` for session-start snapshots and default hook construction.
- Kept `ToolCallFinished.name` in the protocol to preserve reducer-local labeling and avoid secondary correlation maps.
- Mapped runtime todo items into frontend view structs before emission so the protocol stays headless and UI-agnostic.
