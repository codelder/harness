  <action>
    In `src/frontend/protocol.rs`, keep `DEFAULT_FRONTEND_CHANNEL_CAPACITY` at `64` and keep `tokio::sync::mpsc` as the only transport per D-02.

    Replace the current split-pane-oriented event payloads with this exact contract:
    - Add `pub enum FrontendTodoStatus { Pending, InProgress, Completed }`.
    - Add `pub struct FrontendTodoItem { pub id: u32, pub text: String, pub status: FrontendTodoStatus }`.
    - Change these events to carry `turn_id: u64`: `UserMessageCommitted`, `AssistantMessageDelta`, `AssistantMessageCompleted`, `Thinking`, `RetryScheduled`, `Reminder`, and `Error`.
    - Change `ToolCallStarted` and `ToolCallFinished` to carry both `turn_id: u64` and `call_id: String`.
    - Add `TodoSnapshot { turn_id: u64, items: Vec<FrontendTodoItem> }`; reserve `turn_id = 0` for the session-start snapshot.
    - Keep `SessionStarted`, `Status`, and `SessionEnded` unscoped.
    - Mark `TodoSnapshot` as `DeliveryMode::MustDeliver`.

    Preserve the executable backpressure rule from D-02:
    - commands use `send().await`
    - must-deliver events use `send().await`
    - best-effort events use `try_send` plus backlog coalescing

    Do not add `ratatui`, `crossterm`, `stdout`, `stderr`, `TodoManager`, or pane-specific concepts to this module.
  </action>
