## Key Changes

### 1. Theme Module (src/cli/theme.rs)
Created `CliTheme` struct with semantic colors:
- `user` - Cyan/Bold for user messages
- `assistant` - Green for assistant messages
- `thinking` - Gray/Italic for thinking blocks
- `tool` - Yellow for tool calls
- `tool_result` - DarkGray for tool results
- `error` - Red/Bold for errors
- `status` - Blue for status/reminder
- `banner` - Bold for banner
- `composer` - Bold for input area
- `footer` - Magenta for todo footer

### 2. Vec<Line> Render Model
Replaced `timeline_text(&self) -> String` with `timeline_lines(&self) -> Vec<Line<'static>>`:
- Each message type renders with semantic styling
- Simplified format without [turn_id] prefixes

### 3. Simplified Message Format
```

<<< Assistant

[read] README.md
  -> ok

... Thinking
Internal reasoning

!! Error
Something failed
```
