## Decisions Made
- Token usage data IS available via rig-core's `completion::Usage` and `PromptResponse.total_usage`, but the current `chat_with_history_and_hook` returns `String` discarding usage. Wiring requires refactoring LlmProvider, AgentTurn, and agent_loop return types.
- Status line displays tokens only when non-zero to avoid showing misleading "0 in / 0 out" before any LLM call.
- BestEffort delivery mode for TokenUsage ensures high-frequency updates don't block the event channel during streaming.

## Known Stubs
