### Gaps Summary

All 7 requirements are now fully satisfied. The gap identified in the initial verification -- TokenUsage event never emitted by SessionRuntime -- has been resolved by plan 3.2.1-08 which wired the complete emission chain:

1. `LlmProvider::chat_with_history_and_hook()` uses `extended_details()` to get `PromptResponse.total_usage` (provider.rs:135, 143)
2. `agent_loop()` destructures the result into `(response_text, usage)` and propagates into `AgentTurn.usage` (loop_.rs:318, 344-348)
3. `AgentTurn` carries `usage: Option<Usage>` field (message.rs:20)
4. `SessionRuntime::submit_message_with()` emits `FrontendEvent::TokenUsage` after `AssistantMessageCompleted` when `turn.usage` is `Some` (runtime.rs:261-272)
5. `CliApp` receives `TokenUsage` event and stores `input_tokens`/`output_tokens` (app.rs:249-252)
6. `status_line()` renders "N in / M out" prefix when tokens are non-zero (app.rs:477-478)

The test `runtime_emits_token_usage_from_agent_turn` in runtime.rs:694-758 provides automated verification of the full chain. 148 library tests pass with 0 failures.
