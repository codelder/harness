# Phase 3.2.1: TUI Alignment with Claude Code

## Overview

将当前项目的 TUI 体验与 Claude Code CLI 全面对齐，作为整个 UI 的建设指导方案。此 phase 需要纠正之前所有 phase（特别是 3.2）中与此方案 UI 设计矛盾的地方。

## Dependencies

- Phase 3.2: Terminal UI and Frontend Interface Abstraction

## Requirements

### REQ-3.2.1-01: Inline Viewport Mode
使用 ratatui 的 `Viewport::Inline` 模式替代 `EnterAlternateScreen`，使输出保留在终端 scrollback 中。

### REQ-3.2.1-02: Color System
添加完整的语义化颜色系统，区分不同消息类型。

### REQ-3.2.1-03: Spinner Animation
添加 ASCII 花朵动画（·, ✻, ✽, ✶, ✳, ✢）和趣味状态文本。

### REQ-3.2.1-04: Simplified Message Format
简化消息格式，去掉冗长的 `[turn_id]`。

### REQ-3.2.1-05: Enhanced Banner
多行信息面板显示版本/模型/路径/通知。

### REQ-3.2.1-06: Dynamic Todo Display
Todo 完成时自动收起 + 写入历史。

### REQ-3.2.1-07: Enhanced Statusline
显示 token 上下文等更多信息。

## Architecture Decision

**使用 `Viewport::Inline` 替代 `EnterAlternateScreen`**

```rust
// 之前: 全屏接管，退出后历史消失
execute!(stdout, EnterAlternateScreen, EnableMouseCapture)

// 之后: 输出进入 scrollback，历史保留
Terminal::with_options(backend, TerminalOptions {
    viewport: Viewport::Inline(height),
})
```

**优势**:
- ✅ 保留 ratatui 的全部渲染能力
- ✅ 输出进入终端 scrollback 缓冲区
- ✅ 退出后对话历史仍然可见
- ✅ 用户可用终端原生滚动/搜索/复制

## 3.2 阶段需纠正的设计

| 3.2 设计 | 需要纠正为 |
|---------|----------|
| `EnterAlternateScreen` | `Viewport::Inline` |
| 单行 Banner "Harness" | 多行信息面板（版本/模型/路径） |
| 无颜色 | 语义化颜色系统 |
| 静态状态文本 | Spinner 动画 + 趣味文本 |
| `You [turn_id]` 格式 | `>>> You` 简洁格式 |
| Todo 始终固定底部 | 完成时自动收起+写入历史 |
