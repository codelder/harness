### 1. Viewport::Inline Mode
- Replaced `EnterAlternateScreen`/`LeaveAlternateScreen` with `Viewport::Inline(height)`

- Conversation history persists after exit

### 2. Height Calculation
- `calculate_inline_height(terminal_height)` with:
  - `MIN_INLINE_HEIGHT = 10`
  - `MARGIN_LINES = 2`
- Formula: `max(terminal_height - 2, 10)`

### 3. InputEvent Enum
```rust
pub enum InputEvent {
    Key(KeyEvent),
    Resize(u16, u16),  // columns, rows
}
```
- Input listener now returns `InputEvent` instead of just `KeyEvent`
- Resize events pass through to main UI loop

### 4. Resize Handling
- `TerminalGuard::handle_resize()` recalculates inline height
- Returns `true` if viewport height changed
