# TUI 对比研究：当前项目 vs Claude Code CLI

## 研究方法

1. 分析当前项目的 TUI 实现代码
2. 搜索 Claude Code CLI 的 TUI 设计资料
3. 对比两者差异

## 发现的差异

### 1. 终端模式（重大架构差异）

| 特性 | 当前项目 | Claude Code |
|------|---------|-------------|
| 模式 | Alternate Screen（全屏接管） | 直接输出到终端缓冲区 |
| 启动后 | 清空终端，占满全屏 | 在当前终端位置继续输出 |
| 退出后 | 终端恢复原状，内容消失 | 对话历史保留在终端中 |
| 滚动 | 自己实现滚动 | 使用终端模拟器的原生滚动 |

**解决方案**: 使用 ratatui 的 `Viewport::Inline` 模式

### 2. Banner 设计

| 特性 | 当前项目 | Claude Code |
|------|---------|-------------|
| 内容 | 仅 "Harness" | 版本 + 模型 + 路径 + 通知 |
| 行数 | 1 行 | 3-4 行 |
| 功能 | 纯装饰 | 信息面板 |

### 3. 颜色系统

| 特性 | 当前项目 | Claude Code |
|------|---------|-------------|
| 颜色 | 无（仅粗体） | 完整语义化颜色 |
| 主题 | 无 | 可定制 |
| 消息区分 | 纯文本格式 | 颜色 + 样式 |

### 4. Spinner 动画

| 特性 | 当前项目 | Claude Code |
|------|---------|-------------|
| 动画 | 无 | ASCII 花朵动画 |
| 帧序列 | - | `·`, `✻`, `✽`, `✶`, `✳`, `✢` |
| 状态文本 | 静态 | 趣味动态文本 |
| 示例 | "Waiting..." | "Sketching...", "Reticulating...", "Beep boop..." |

### 5. 消息格式

**当前项目**:
```
You [1]
Hello

Assistant [1]
Hi there!

Tool [1:read-1] read
args: README.md
result: ok
```

**Claude Code**:
```
>>> You
Hello

<<< Assistant
Hi there!

[read] README.md
  -> ok
```

### 6. Todo 显示

| 特性 | 当前项目 | Claude Code |
|------|---------|-------------|
| 显示方式 | 始终固定底部 | 混合模式 |
| 完成后 | 继续显示 | 自动收起 + 写入历史 |

**Claude Code 的混合模式**:
- 当有 active todo 时，固定显示在底部
- 当 todo 全部完成时，自动收起
- 完成的 todo 记录会添加到消息流中作为历史

### 7. Statusline

| 特性 | 当前项目 | Claude Code |
|------|---------|-------------|
| 内容 | 状态 + 快捷键提示 | 高度可定制 |
| Token 显示 | 无 | 有 |
| 模型显示 | 在连接状态中 | 始终可见 |
