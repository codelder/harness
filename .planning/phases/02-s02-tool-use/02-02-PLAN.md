```rust
// Safety blacklist check
let dangerous_patterns = [
    "rm -rf /",
    "rm -rf /*",
    "sudo",
    "mkfs",
    "fdisk",
    "shutdown",
    "reboot",
    "halt",
    "dd if=",
    "> /dev/sd",
];

for pattern in &dangerous_patterns {
    if args.command.contains(pattern) {
        return Err(BashError::Blocked(
            format!("contains '{}'. This operation requires explicit user confirmation.", pattern)
        ));
    }
}
```

3. The existing command execution code should remain unchanged after this check.

The blacklist check must happen BEFORE any command execution.
