Wire TodoTool into the provider creation chain and detect tool usage to reset rounds_since_todo.

Output: Updated provider.rs with TodoTool registration, updated SYSTEM_PROMPT, usage detection via generation counter.

**Key Changes from Review:**
1. Remove `updated: bool` field - use generation counter instead
2. Remove `was_updated()` / `clear_updated()` methods - solve the wrong problem
3. Use a generation counter in TodoManager that increments on each update
4. Session tracks last_seen_generation and resets counter when it changes

**Why generation counter instead of updated flag:**
- Cleaner semantics: generation naturally increments, no clear step needed
- More robust: no race condition between check and clear
- Simpler: one check instead of check + clear pattern

pub fn update(&mut self, items: Vec<TodoItem>) -> Result<String, TodoError> {
    // Validate max 20 items
    if items.len() > 20 {
        return Err(TodoError::TooManyItems(items.len()));
    }
    // Validate only one in_progress
    let in_progress_count = items.iter()
        .filter(|i| i.status == TodoStatus::InProgress)
        .count();
    if in_progress_count > 1 {
        return Err(TodoError::MultipleInProgress(in_progress_count));
    }
    self.items = items;
    self.generation += 1;  // Increment generation on successful update
    Ok(self.render())
}

Update the agent response handling to detect generation changes:
```rust
match agent_loop(&self.messages, line, &provider).await {
    Ok(turn) => {
        debug!(response_len = turn.response.len(), "Agent response received");

        // Check if todo was updated and reset counter
        // Using generation counter instead of updated flag (per review feedback)
        if let Ok(manager) = self.todo_manager.lock() {
            if manager.generation() != self.last_todo_generation {
                self.rounds_since_todo = 0;
                self.last_todo_generation = manager.generation();
            }
        }

        // Build the response with optional nag reminder
        let response = if self.rounds_since_todo >= 3 {
            let has_todos = self.todo_manager.lock()
                .map(|m| !m.is_empty())
                .unwrap_or(false);
            if has_todos {
                format!(
                    "<reminder>You have pending todos. Use the 'todo' tool to update your task list.</reminder>\n\n{}",
                    turn.response
                )
            } else {
                turn.response
            }
        } else {
            turn.response
        };

        println!("{}", response);

        // Increment round counter after each agent response
        self.rounds_since_todo += 1;

        // Commit the turn to history only on success
        self.messages.push(Message::user(&turn.user_input));
        self.messages.push(Message::assistant(&turn.response));
        self.turn_count += 1;
    }
    // ... error handling unchanged
}
```

**Key design:**
- Generation check happens BEFORE building the response (so if todo was just updated, rounds_since_todo is already reset)
- No helper methods - logic is inline
- No `was_updated()` / `clear_updated()` pattern - just compare generations
