This task addresses the need to reset rounds_since_todo when the todo tool is called.

The challenge is that rig-core's Agent handles tool calls internally - we don't have direct access to when tools are called.

Two approaches:

**Approach A (Recommended): Check after agent_loop returns**
After agent_loop returns, check if the TodoManager was modified by comparing a hash or timestamp. If modified, reset rounds_since_todo.

However, this is complex without adding metadata to TodoManager.

**Approach B (Simpler): Poll TodoManager state**
Store a "last seen item count" and reset counter if count changes.

For this implementation, we'll use Approach B with a simple modification counter:

1. Add a generation counter to TodoManager (in planning/todo.rs):
```rust
pub struct TodoManager {
    items: Vec<TodoItem>,
    generation: u64,  // Incremented on each update
}

impl TodoManager {
    pub fn generation(&self) -> u64 {
        self.generation
    }
    // In update(), increment generation after successful update
}
```

2. In Session, track last_seen_generation:
```rust
pub struct Session {
    // ... existing fields
    last_todo_generation: u64,
}
```

3. After agent_loop returns, check if generation changed:
```rust
// After agent response
if let Ok(manager) = self.todo_manager.lock() {
    if manager.generation() != self.last_todo_generation {
        self.rounds_since_todo = 0;
        self.last_todo_generation = manager.generation();
    }
}
```

Actually, let me simplify this further. The RESEARCH.md suggests the todo tool can provide a callback or we can check state. The simplest approach is to check if the todo list has changed.

For now, let's use a simpler approach: store the hash of the current todo state and compare after each turn.

Implementation:
1. Add method to Session to check if todo state changed and reset counter if so
2. Call this method after agent_loop returns

This is getting complex. Let me use the most straightforward approach per RESEARCH.md:

The TodoTool has get_manager() which returns the Arc. We can't easily detect when it's called from within Session.

Alternative: Use a flag in TodoManager that gets set when update is called.

For simplicity in this phase, we'll add a was_updated flag that can be checked and cleared:

In TodoManager:
```rust
pub struct TodoManager {
    items: Vec<TodoItem>,
    updated: bool,  // Set to true on each update
}

impl TodoManager {
    pub fn was_updated(&self) -> bool {
        self.updated
    }

    pub fn clear_updated(&mut self) {
        self.updated = false;
    }

    pub fn update(&mut self, items: Vec<TodoItem>) -> Result<String, TodoError> {
        // ... validation ...
        self.items = items;
        self.updated = true;  // Set flag
        Ok(self.render())
    }
}
```

In Session::run(), after agent_loop returns:
```rust
// Check if todo was updated and reset counter
if let Ok(mut manager) = self.todo_manager.lock() {
    if manager.was_updated() {
        self.rounds_since_todo = 0;
        manager.clear_updated();
    }
}
```
