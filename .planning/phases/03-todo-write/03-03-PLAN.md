Add TodoUsageHook struct:
```rust
/// Hook that tracks whether the todo tool was called during agent execution.
///
/// This implements direct tool call detection (per Python reference implementation)
/// instead of indirect detection via TodoManager state changes.
pub struct TodoUsageHook {
    /// Flag set to true when todo tool is called
    used_todo: Arc<AtomicBool>,
}

impl TodoUsageHook {
    /// Create a new hook with a shared flag
    pub fn new() -> (Self, Arc<AtomicBool>) {
        let used_todo = Arc::new(AtomicBool::new(false));
        let hook = Self {
            used_todo: used_todo.clone(),
        };
        (hook, used_todo)
    }
}

// Note: PromptHook implementation requires the CompletionModel generic parameter.
// This will be implemented in provider.rs where the model type is known.
```

**Key design:**
- The hook stores an `Arc<AtomicBool>` that gets set to `true` when todo tool is called
- Session receives a clone of this Arc and checks it after agent_loop returns
- No state pollution in TodoManager - detection is purely at dispatch level
- This is the EXACT equivalent of Python's `used_todo = True` in the tool loop

**Important:** The actual `impl PromptHook` will be in provider.rs because:
1. PromptHook is generic over the CompletionModel type
2. The model type is only known at provider creation time
3. This keeps loop_.rs provider-agnostic

**Tool usage detection:** After agent_loop returns, check the used_todo flag (set by TodoUsageHook) and reset counter if todo was used.

Find the location after agent_loop returns successfully (around line 76-83 in the original file), and modify the response handling:

```rust
match agent_loop(&self.messages, line, &provider, &used_todo_flag).await {
    Ok(turn) => {
        debug!(response_len = turn.response.len(), "Agent response received");

        // Check if todo was used (directly from dispatch, per Python approach)
        // This is equivalent to Python's: rounds_since_todo = 0 if used_todo else rounds_since_todo + 1
        if used_todo_flag.load(Ordering::SeqCst) {
            self.rounds_since_todo = 0;
            used_todo_flag.store(false, Ordering::SeqCst); // Reset for next turn
        }

        // Build the response with optional nag reminder
        // Per Python reference: inject reminder into response for model visibility
        let response = if self.rounds_since_todo >= 3 {
            let has_todos = self.todo_manager.lock()
                .map(|m| !m.is_empty())
                .unwrap_or(false);
            if has_todos {
                format!(
                    "<reminder>You have pending todos. Use the 'todo' tool to update your task list.</reminder>\n\n{}",
                    turn.response
                )
            } else {
                turn.response
            }
        } else {
            turn.response
        };

        println!("{}", response);

        // Increment round counter after each agent response
        self.rounds_since_todo += 1;

        // Commit the turn to history only on success
        // Store the original response (without reminder) in history
        self.messages.push(Message::user(&turn.user_input));
        self.messages.push(Message::assistant(&turn.response));
        self.turn_count += 1;
    }
    // ... error handling unchanged
}
```

**Important design notes:**
1. The reminder is prepended to the displayed response, making it model-visible
2. The history stores the original response WITHOUT the reminder (the reminder is transient)
3. The rounds_since_todo counter is reset BEFORE building response (if todo was just used)
4. The counter is incremented AFTER the response
5. No helper methods - logic is inline and simple
6. Tool usage detection is DIRECT (via hook flag), not INDIRECT (via TodoManager state)

**Note:** This task requires agent_loop signature to accept the used_todo_flag. That change is in Plan 04 Task 3.
